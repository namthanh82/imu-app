# Workflow

1. Ensure the IMU hardware is connected to the correct COM port (default `COM14`).
2. Run the Python backend (`python app.py`).
3. Access the web dashboard (`http://127.0.0.1:5555`).
4. Enter Calibration phase, test offset.
5. Create/Select a patient and start a measurement session.
6. Check 3D model visualization and live charts during the session.
7. Stop the session, export data to CSV.
8. Use AI to generate clinical reports based on the recorded session.
